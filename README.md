CARA - An E-Commerce Website
---

## 🚀 Features

- 🔥 Stylish & responsive layout using Google Fonts (Poppins)
- 🛍️ 8 Featured products in the Shop section
- 🧺 Interactive Bag/Cart page
- 📰 Blog section with cards and latest news
- 💼 About page with mission, vision, and brand story
- 💬 Feedback form stored using MySQL (optional)
- ✅ Font and color consistency across all pages

---

## 🖥️ Technologies Used

- HTML5
- CSS3 (Inline & Internal)
- Google Fonts (`Poppins`)
- phpMyAdmin (for Feedback/Cart database - optional)
